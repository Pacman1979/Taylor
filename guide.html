Section 3

Setting up GitHub

GitHub stores your website code. The good news is you don't need to install anything — you can edit your website directly in your browser.

Creating your GitHub account

  1. Go to github.com and click "Sign up"

  2. Enter your email address, create a password, and choose a username (something like taylorbreaththerapy is fine)

  3. Verify your email address when GitHub sends you a confirmation

  4. Once logged in, go to github.com/Pacman1979/Taylor — this is where your website lives

Tip: Bookmark github.com/Pacman1979/Taylor/blob/main/index.html — this takes you directly to your website file for editing.

Getting access to your website's repository

Your website is currently managed under Phil's GitHub account. To get your own full access, Phil can add you as a collaborator:

  1. Send Phil your GitHub username once you've created your account

  2. Phil will add you as a collaborator — you'll receive an email invitation

  3. Accept the invitation and you'll have full edit access

Editing your website in GitHub (no code needed)

  1. Go to github.com/Pacman1979/Taylor/blob/main/index.html

  2. Click the pencil icon ✏️ in the top right of the file view

  3. The file will open in an editor — use Ctrl+F (or Cmd+F on Mac) to search for the text you want to change

  4. Make your changes directly in the editor

  5. When done, scroll down and click "Commit changes"

  6. Type a short description of what you changed (e.g. "Update July events") and click "Commit changes" again

  7. Your live website will update automatically within 60 seconds ✅

Tip: Always write a clear commit message. It helps you keep track of what you changed and when. For example: "Add August breathwork event" or "Update Instagram followers to 2,100".

Section 4

Making website changes

Here are the most common things you'll want to update, with exactly where to find them in your website file.

Updating the announcement bar

The black bar at the very top of your website. To change it:

  1. Open your website file in GitHub and click the pencil to edit

  2. Press Ctrl+F and search for "NOW TAKING BOOKINGS"

  3. Change the months (e.g. "August & September" → "October & November")

  4. Commit the change

Updating upcoming events

To add or change events in the Upcoming Sessions section:

  1. Search in the file for "ADD NEW EVENTS HERE" — this is the marker where new events go

  2. Copy an existing event block and change the date, title, location, time and price

  3. Update the Luma link to point to the correct booking page (see Section 6)

  4. Delete any past events that are no longer relevant

Tip: If this feels complicated, just ask Claude AI to do it for you. Paste in the event details and Claude will write the exact code to add. See Section 5.

Adding a new Google review

  1. Search for "Love Notes" in the file to find the reviews section

  2. Copy an existing review card block and replace the quote, name and tag

  3. Paste it before the dark Google review card (which should always be last)

Updating Instagram followers

  1. Search for the current follower number (e.g. "1,962")

  2. Change it to the new number

  3. Commit the change

Changing a photo

  1. Go to github.com/Pacman1979/Taylor and click the images folder

  2. Click "Add file" → "Upload files"

  3. Upload your new photo — use a simple filename with no spaces (e.g. Taylor-new.jpg)

  4. In the website file, search for the old photo filename and replace it with the new one

⚠️ Photo file sizes: Keep photos under 2MB where possible. Large files slow down your site. Use your phone's built-in editing tools to reduce size if needed.

Section 5

Using Claude AI to make changes

Claude is an AI that understands your website and can write the code changes for you. Think of it as having a web developer on call — you just describe what you want in plain English.

Getting started with Claude

  1. Go to claude.ai and create a free account with your email

  2. Start a new conversation

  3. Copy and paste the section of your website file that you want to change, then describe what you want done

  4. Claude will write the updated code for you

  5. Copy Claude's output and paste it into the right place in your GitHub file

Example prompts you can copy and use

I manage a website for a breathwork business called The Breath Therapy. I need to update the upcoming events section. Please add this new event: [event name], [date], [location], [time], [price]. The Luma booking link is [your Luma link]. Can you write the HTML code for this event row so I can paste it into my website?
I have a new 5-star Google review I'd like to add to my website's Love Notes section. The review is from [Name] and says: "[review text]". Can you write the HTML card code for this review so I can add it to my website?
I need to update the announcement bar at the top of my website to say "Now taking bookings for October & November events on the Gold Coast & Melbourne". Can you tell me exactly what text to search for and what to replace it with?
Something on my website looks broken — [describe what you see]. Here is the relevant section of my HTML code: [paste the code]. Can you help me fix it?

Tips for getting the best results from Claude

  • Be specific — the more detail you give, the better the result
  • Always tell Claude it's an HTML website for The Breath Therapy
  • If the result isn't right, just say "that's not quite what I meant" and describe it differently
  • Ask Claude to explain what it changed if you want to understand it
  • You can paste screenshots into Claude to show it what something looks like

Managing Luma events

Luma is where people actually book and pay for your sessions. Your website links to Luma — it doesn't handle payments directly. When you create a new event on Luma, you'll need to update the link on your website.

Getting your Luma event link

  1. Log into lu.ma and create your new event

  2. Once published, copy the event URL from your browser — it'll look like lu.ma/abc123

  3. Update the relevant "Book Now" link on your website to use this new URL

Current Luma links on your website

  • Melbourne Breathwork — lu.ma/9ju5ms11

Tip: When you create a new round of events, create a new Luma calendar or event group and update all the relevant links on your website at once.

Section 7

Your professional email

Your email address taylor@thebreaththerapy.com.au is set up to forward all emails into your existing Gmail account. This means you don't need to check a separate inbox — everything comes to you in Gmail as usual.

If emails stop arriving

  1. Log into dash.cloudflare.com

  2. Click on thebreaththerapy.com.au

  3. Click Email → Email Routing

  4. Check that the routing rule is enabled and pointing to your Gmail

Sending emails from your professional address

To send emails from taylor@thebreaththerapy.com.au (rather than your Gmail address) you can set this up in Gmail settings:

  1. In Gmail, click the cog icon ⚙️ → See all settings

  2. Click the Accounts and Import tab

  3. Under "Send mail as" click "Add another email address"

  4. Enter Taylor Valentino and taylor@thebreaththerapy.com.au

  5. Follow the verification steps

Section 8

Domain renewal

Your domain name thebreaththerapy.com.au needs to be renewed each year through VentraIP. The cost is approximately $27/year.

⚠️ This is the most important thing not to forget. If your domain expires, your website, your professional email, and everything connected to thebreaththerapy.com.au will go offline until it's renewed.

How to renew

  1. Log into ventraip.com.au

  2. Go to My Services → Domain Names

  3. Click Renew next to thebreaththerapy.com.au

  4. Pay the renewal fee

Tip: Set up auto-renewal in VentraIP with a credit card on file so it renews automatically every year without you having to remember.

Section 9

If something breaks

Don't panic. Websites can be fixed. Here's how to diagnose what's wrong.

The whole site is down

  • Check cloudflarestatus.com — there may be a Cloudflare outage
  • Check your domain hasn't expired in VentraIP
  • Wait 10 minutes and try again from a different device or incognito window

A change I made broke something

  • Go to github.com/Pacman1979/Taylor/commits/main
  • Find your last commit and click the three dots ··· → "Revert"
  • This undoes your last change and restores the previous version

Something looks wrong but the site is up

  • Try a hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  • Try opening the site in an incognito/private window
  • Describe the issue to Claude AI with a screenshot — it can usually diagnose and fix it

My email isn't working

  • Check Cloudflare Email Routing is still enabled (see Section 7)
  • Check your Gmail spam folder
  • Make sure your Gmail verification for the destination address hasn't expired
